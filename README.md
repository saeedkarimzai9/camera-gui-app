# 📷 Camera GUI App - Easy Mode

A simple Windows desktop application that lets you access your camera with a graphical interface and apply cool effects!

## Features ✨

- **Live Camera Feed** - See your camera in real-time
- **Visual Effects** - Apply filters like grayscale, blur, edge detection, and flip
- **Take Snapshots** - Capture photos from your camera
- **Easy Controls** - Simple buttons to start/stop and switch effects
- **Windows Compatible** - Works perfectly on Windows PC

## Requirements

- Python 3.7 or higher
- Windows operating system
- A working webcam

## Installation & Setup 🚀

### Step 1: Install Python
Download and install Python from [python.org](https://www.python.org/downloads/)
Make sure to check **"Add Python to PATH"** during installation!

### Step 2: Clone or Download This Project
```bash
git clone https://github.com/saeedkarimzai9/camera-gui-app.git
cd camera-gui-app
```

### Step 3: Install Dependencies
Open Command Prompt in the project folder and run:
```bash
pip install -r requirements.txt
```

### Step 4: Run the App
```bash
python main.py
```

## How to Use 🎮

1. **Click "▶ Start Camera"** - Opens your webcam
2. **Click Effect Buttons** - Apply effects to your camera feed:
   - **Normal** - No effects
   - **Grayscale** - Black & white
   - **Blur** - Blurry effect
   - **Edge Detection** - Shows edges
   - **Flip H** - Mirror horizontally
   - **Flip V** - Mirror vertically
3. **Click "📸 Take Snapshot"** - Saves a photo as `snapshot.jpg`
4. **Click "⏹ Stop Camera"** - Closes the camera

## Troubleshooting 🔧

**Camera won't start?**
- Make sure your webcam is plugged in and working
- Check if another app is using your camera
- Try restarting the app

**Getting errors when running?**
- Make sure all dependencies are installed: `pip install -r requirements.txt`
- Check that Python is properly installed
